# carrerotas
las carrerotas de natitata y brunotete

1. FUNCION ANIDADA CARGAR COMPETIDORES PENDIENTE + PREGUNTA MONSE
2. TITULO EN ARREGLO POR QUE SE VE FEO (tambien por el ego de bruni)
3. LIMPIAR CONSOLA DESPUES DE CADA COSA PARA QUE SE VEA ORGANIZADO (esto es por el ego de natita)
4. BUSCAR UN LUGAR DONDE USAR \t (esto nadamas es por el ego de bruni)
5. DOS ULTIMAS PAGINAS Y MEDIA 
6. DOCUMENTO
7. PONER EN DO WHILE LOS MENUS QUE NO ESTAN EN DO WHILE
